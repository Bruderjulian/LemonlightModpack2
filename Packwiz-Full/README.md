# Packwiz-Full (Lemonlight Full)

[Packwiz](https://github.com/comp500/packwiz) sources for the Lemonlight Full edition: the normal edition (`../Packwiz/`) plus extras (shader support, controllers, e4mc, capes, hi-res screenshots, mount HUD).

This folder is generated - do not edit it by hand except for Full-only mods. To rebuild it from `../Packwiz/`, run from the repo root:

```sh
python "CLI tools/Build full variant.py" --all
```

See the [Developer section](../README.md#developer-section) for details.
