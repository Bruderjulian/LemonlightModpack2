# Packwiz (Lemonlight, normal)

[Packwiz](https://github.com/comp500/packwiz) sources for the normal Lemonlight edition: one folder per supported Minecraft version (1.19.x and newer), each with `pack.toml`, `index.toml`, `mods/*.pw.toml`, `config/` and `resourcepacks/`.

The Full edition lives in `../Packwiz-Full/` and is generated from these folders plus extras - see the [Developer section](../README.md#developer-section) and [`../CLI tools/Build full variant.py`](../CLI%20tools/Build%20full%20variant.py). Do not edit `Packwiz-Full/` by hand except for Full-only mods; re-run the script instead.
