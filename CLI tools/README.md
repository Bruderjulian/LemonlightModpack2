These files are for the maintainer(s) of Lemonlight, used to copy files faster across folders.

- `Build full variant.py` - rebuilds `Packwiz-Full/` from `Packwiz/` plus the Full-only extras (`--all` or `--version <mc>`).
- `Update version.py` - bumps the pack version (instance title text, manifests).
- `CurseForge to MultiMC-Git.py`, `MultiMC to Git.py`, `CurseForge to Packwiz-Modrinth.py` - inherited from upstream for moving files between launchers/formats; instance and project names now say Lemonlight.
